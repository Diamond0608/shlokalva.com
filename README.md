# Shlok Alva Portfolio

Local-first React portfolio for `shlokalva.com`, built with Vite, TypeScript, React Three Fiber, Framer Motion, and a static deployment target suitable for Cloudflare Pages.

## Run Locally

```bash
npm install
npm run dev
```

The dev server opens on localhost. For a production build:

```bash
npm run build
```

Cloudflare Pages can use `npm run build` with `dist` as the output directory.

## Content Notes

The portfolio copy is based on the supplied brag-sheet material and the direct project brief, with academic scoring details left out.
